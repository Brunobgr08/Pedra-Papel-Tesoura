## 🎯 Sobre o Projeto

Uma aplicação interativa de Pedra, Papel e Tesoura desenvolvida com tecnologias web modernas. O jogo oferece uma experiência visual atraente com animações suaves, design responsivo e paleta de cores tecnológica.

### 🎮 Como Funciona

1. O usuário insere seu nome
2. Escolhe entre Pedra, Papel ou Tesoura
3. O computador faz uma escolha aleatória
4. A função de comparação determina o vencedor
5. Placar é atualizado automaticamente

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos modernos com gradientes e animações
- **JavaScript (Vanilla)** - Lógica do jogo sem dependências
- **Responsive Design** - Mobile-first approach

## 🔧 Instalação Local

```bash
# Clone o repositório
git clone https://github.com/brunobgr08/Pedra-Papel-Tesoura.git

# Navegue até o diretório
cd Pedra-Papel-Tesoura

# Abra o arquivo index.html no navegador
# Ou use um servidor local:
python -m http.server 8000
# Acesse http://localhost:8000
```
